# Athurugiriya → Trincomalee Group Trip Itinerary

This trip has gone through multiple plan revisions. Each one is kept as a
separate, complete document rather than overwritten, so earlier versions
stay available for comparison:

- [`plans/plan-01.md`](plans/plan-01.md) — original plan (kayaking Day 1
  morning, Pigeon Island Day 2 morning, Day 2 returns to Verandas for an
  afternoon rest block)
- [`plans/plan-02.md`](plans/plan-02.md) — kayaking moved to the Day 2 return
  leg; Day 2 no longer returns to Verandas; breakfast pushed to 7:00 AM
- [`plans/plan-03.md`](plans/plan-03.md) — **current** — kayaking stays on
  Day 1 morning (extended to 120 min); Velgam Vehera and Kanniya move to
  Day 2 (near Nilaveli) to make room; Day 2 still never returns to Verandas

The live site mirrors this structure with a plan-switching dropdown — see
`src/data/plans/` and `src/pages/plans/[plan].astro`. When the plan changes
again, add a new `plans/plan-0N.md` here rather than editing an existing one;
see `.claude/skills/update-trip-plan/SKILL.md` for the full process.
